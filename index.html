A private AI voice assistant.
On your server.

LivaChat is a native iOS client for the open-source LivaChat server. One-time purchase. No account. No subscription. No tracking. Your conversations go directly to the server you run.

Get help Privacy Policy

Private by design

The developer does not operate a server and does not collect your data. Audio, video, and text go directly to the server you configure.

Your server

Run LivaChat on your own Mac, Linux machine, or cloud instance. You control the model providers, storage, retention, and access.

No account

No sign-up, no login, no subscription. Connect the app to your server with its address and auth key.

Open source

The server and client source code are available on GitHub. Inspect, build, and modify them under the Apache 2.0 license.

How it works

  1. Install and start the open-source LivaChat server on hardware you control.
  2. Open the iOS app and enter your server address and auth key.
  3. Start a voice or text conversation. Data flows directly between the app and your server.

LivaChat does not provide hosting. You need your own LivaChat server to use the app. Setup instructions and source code are available at github.com/livachat99.

Requirements

  • iPhone running iOS 15.0 or later.
  • A LivaChat server you control, reachable from your device.
  • Microphone permission for voice conversation; camera permission is optional.
