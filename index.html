LivaChat — Private AI voice assistant on your server

LivaChat delivers real-time voice and visual AI chat, live transcription and translation, a time-machine timeline of your conversations and media, plus Hermes and OpenClaw agent integration for long-running tasks like news analysis, finance reports, and research.

Introduction

ℹ️ LivaChat is a complete real-time AI chat platform: a self-hosted server plus native iOS and Android clients, built on the same open-source stack.

ℹ️ Run the server on your own Mac, Linux machine, or cloud VM. Voice, video, and text travel directly between the app and your server.

ℹ️ No account, no subscription, no tracking. You choose the model providers and control your own data.

Architecture

Core Advantages

Private by design:

✅ The developer does not operate a server and does not collect your data. Audio, video, and text go directly to the server you configure.

Your server, your rules:

✅ Run LivaChat on macOS, Linux, or a cloud VM. You control the model providers, storage, retention, and access.

No account:

✅ There is no sign-up and no login. Connect the app with your server address and auth key.

Open source:

✅ The server and clients are released under the Apache License 2.0. Inspect, build, and modify them on GitHub.

Real-time multimodal:

✅ Low-latency duplex voice, live transcription and translation, and vision in one conversation.

Agent-ready:

✅ Connect Hermes or OpenClaw agents and drive long-running tasks by voice or chat.

Quick Installation

Installation Notes

✅ The server installs and starts with one script: ./livachat.sh install, then ./livachat.sh start.

ℹ️ LivaChat runs on macOS, Linux, and Windows via WSL2. Python 3.12 is installed automatically by the setup script.

⚠️ You need ffmpeg, libopus, and an Alibaba Bailian (DashScope) API key before starting the server.

Quick Start

  1. Install the media prerequisites for your platform. 
    # macOS (Homebrew)
brew install ffmpeg opus

# Ubuntu / Debian
sudo apt update && sudo apt install -y ffmpeg libopus0

# Fedora
sudo dnf install -y ffmpeg-free opus

# Arch Linux
sudo pacman -S --needed ffmpeg opus
  2. Clone the repository and run the installer. 
    git clone https://github.com/livachat99/livachat.git
cd livachat
./livachat.sh install
  3. Configure the server. 
    cp .env.example .env
# Edit .env and fill in:
#   DASHSCOPE_API_KEY
#   DASHSCOPE_API_HOST
#   DASHSCOPE_WORKSPACE_ID
#   APP_AUTH_TOKEN
  4. Start the server and check its health. 
    ./livachat.sh start
./livachat.sh status
  5. Open the app and connect.

    Enter your server address (for example https://<server-host>:8080) and the APP_AUTH_TOKEN from your .env. If your server uses a self-signed certificate, enable "Allow self-signed certificates" in Settings.
